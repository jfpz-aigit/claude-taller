# Claude Taller

Proyecto de práctica para aprender el flujo de trabajo de Pull Requests con Claude Code.

## Contenido

- `greetings.py`: funciones sencillas de saludo (`greet`, `shout`).

## Uso

```python
from greetings import greet, shout

greet("Juan")   # "Hola, Juan!"
shout("hola")   # "HOLA!"
```

## Tests

```bash
python -m pytest
```
